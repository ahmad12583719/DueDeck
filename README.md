# FocusFlow Task Manager

A dependency-free, responsive task manager built with native ES modules. It stores tasks in `localStorage`, includes list/calendar views, search and filters, deadlines, recurring tasks, subtasks, tags, drag-and-drop ordering, notifications, rich descriptions, JSON backup, and light/dark themes.

Open `index.html` in a modern browser. No build step is required. Data schema is versioned (`focusflow.v1`) and seeded with three demo tasks on first launch.
